# PulseDesk

Responsive customer support dashboard concept focused on ticket triage, operational metrics and team workload visibility.

## Features

- Ticket search and status filtering
- Support metrics and weekly conversation volume
- Responsive dashboard layout
- Accessible, reusable interface components

## Stack

- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- Vinext and Vite

## Development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Status

Personal concept project created as a UI and front-end engineering portfolio piece.
